# 🧮 Calculadora de Desconto

Este projeto é uma calculadora de desconto desenvolvida durante meus estudos de programação.

A aplicação recebe o preço de um produto e aplica automaticamente 10% de desconto quando o valor informado é superior a R$ 30,00.

## 🚀 Funcionalidades

- Recebimento do preço do produto
- Verificação do valor informado
- Aplicação automática de 10% de desconto
- Exibição do preço original
- Exibição do valor do desconto
- Cálculo e exibição do preço final
- Formatação dos valores em reais
